# 历史交付材料

本目录保存此前生成的独立交付版本，便于追溯，不作为当前工具箱运行入口。

- `x-twitter-crawler-logic` 与对应 ZIP：2026-09-26 的 X/Twitter 采集逻辑包。
- `weekly-image-copyright-20261003` 与对应 ZIP：2026-10-03 的周报图片采集与管理软件软著准备材料，包括当时的源码副本。申请资料仍需按材料说明核对，不能视为已提交或已登记。

当前工具箱使用仓库主目录的 `启动工具箱.pyw` 和 `src/galgame_news`。这些历史源码副本不随主程序修复同步更新。

主目录 `galnews.py`、`galnews_v2.py` 为早期独立命令行入口，凭据通过环境变量提供；现行工具箱的凭据管理和每任务 SocialData 开关位于主源码链路中。
