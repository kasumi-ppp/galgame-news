# CG 原图证据与离线重筛

## 证据链

图库 DOM 区域中的图片，通过明确的 anchor、picture/source、srcset、大图属性或单图弹窗引用关联原图。每个候选保留 `gallery_evidence_source`、`media_variant_of`；Logo、页头、角色、商品和特殊活动区域用 `gallery_excluded_reason` 排除。页面标题、OGP 和文件名不能独立提供图片级图库证据。

来源链必须回到当前新闻的官方作品入口；同域不是作品证明。发行商首页需要作品名匹配，作品内的 related、recommend、game/product/work/title 路径边界不能被当成同作品。日文标题与英文新闻名不同、品牌或周年文字不是其他作品的充分证据；明确的 other_game_name、conflicting_entity 和 Steam ID 冲突仍优先处理。

官网作品关联成立且有图片级 CG 证据时，分类置信度使用 0.92。CG 更新之外的新闻也可选取合格的 CG。通用类型门槛不降低；不确定素材仍保留可打开的审阅图。

## 旧数据恢复与去重

旧索引只在同一新闻、同一来源页面内向图片继承证据，捐赠图片本身必须通过作品关联与 CG 分类。感知哈希仅是预筛，必须再确认解码像素。恢复前保存原始元数据快照；下一次筛选先恢复快照并清除旧的派生分类、冲突、评分和重复关系，避免上次推导变成新证据。

重复确认同时检查尺寸比例、平均像素差、显著差异比例和局部区域差异；不同表情不能因大部分背景一致而被合并。比较缓存最多保存 128 张标准化小图，不缓存大尺寸原件。重复组中优先保留合格且原始细节更好的版本；X API 图片优先级和每新闻 20 张上限保持现有规则。

## 发布与审阅

在原子替换 raw 目录前，递归重写内存结果、manifest 和所有已生成 JSON 中的审阅图、原件等路径，指向最终目录。发布失败恢复旧 raw 与内存候选状态。旧 `.work/publish-*` 路径仅可映射到同一任务的 raw，校验哈希与解码后使用，不按文件名在其他任务中搜索。

离线重筛入口：

```powershell
E:\Anaconda3\python.exe scripts/reselect_local_images.py output/262-20261002T114050-9ddeb2a6
```

自动新建 `output/262_cg_fix_<时间戳>`，保留 raw、final、逐图原因对照、逐新闻统计、联系图和 HTML 预览。脚本验证编码、扩展名、哈希、源目录未变、审核导入与人工导出；不调用网络、付费 API、LLM 或视频下载。

## 本次数据的限制

One Night After 的部分缩略图带滤色，PNG 和 WebP 的同编号图片也可能对应不同画面。因此不能按编号恢复全部原图证据。已确认的同画面优先选清晰原图；未能确认的原图保留待复核并提供原链接。离线重筛不能补回原任务中三条整批下载失败、未留下图片候选的新闻。
