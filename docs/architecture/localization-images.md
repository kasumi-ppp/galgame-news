# 汉化新闻图片策略

本策略只对 `section_prefix(item.section) == "h"` 的汉化新闻生效。其他分节继续走现有图片筛选流程。Steam 与 VNDB 适配器按 `search.max_candidates_per_source` 收集候选（单独调用时使用 `CollectionContext.max_candidates`）；自动入选仍以每条新闻 20 张为上限。候选预算优先保存原图，随后保存预览变体及关联作品参考图；视频下载保持原有行为。

## 作品绑定与来源

- 图片必须追溯到 Steam 或 VNDB，并且作品 ID 必须与本条新闻显式记录的作品 ID 对应。
- `confirmed` 表示当前作品绑定。`reference` 表示相关参考作品，允许进入人工复核，但不自动入选。`uncertain` 同样只能人工复核；显式绑定冲突、标志和装饰素材会被拒绝。
- 页面来源还必须能关联到本条新闻。公共图库、普通宣传图和角色素材不会仅因作品或来源匹配而成为本条汉化新闻的配图。

## 自动入选条件

自动入选要求同时满足：当前作品的 `confirmed` 绑定、来源关联、图片级截图证据、完整原图及原生图片证据、下载成功、图片解码和审阅图转换无错误、存在可复核的本地文件，以及实际尺寸至少长边 800、短边 450、像素总数 360,000。来源给出预期尺寸时，实际尺寸不符也会阻止自动入选。

满足以上条件的截图归为 `gameplay_screenshot`，置信度为 0.90。只有图片级证据明确标记 `event_cg` 的图片才归为 `game_cg`，置信度为 0.92，排序优先级高于普通游戏截图；CG 也必须通过相同的自动入选门槛。

未达到自动入选门槛但仍可复核的图片、关联参考或待确认绑定等图片保留给人工处理。所有栏目的“未候选”审核和导出统一排除原始长边不足 800 或短边不足 600 像素的图片（竖图按同样规则处理）；尺寸未知的失败记录不因该规则消失。Logo、装饰素材、未下载或无法解码的图片不会被该策略提升为游戏画面。

“未候选”只显示同一新闻中不同的画面：已有可用已选版本时隐藏其重复备选，否则按原始细节质量保留一个备选。重复必须通过内容哈希，或感知哈希加解码像素比较确认，不能只靠文件名或相似构图。过滤仅影响审核列表和用户交付目录，全部候选记录、来源链接和原件仍保留；人工明确已选的图片不被这项备选过滤移除。旧结果重新打开审核页即采用此规则，已有导出目录需重新导出后更新。

## 时间与其他优先规则

作品原有的旧截图只要满足当前作品绑定及原图质量要求，就可以作为汉化新闻配图；本策略不额外要求截图发布日期必须接近汉化新闻日期。

现有 X API 照片优先机制保持不变。汉化策略不覆盖其排序优先级，也不改变新闻、图片或视频的其他筛选规则。
