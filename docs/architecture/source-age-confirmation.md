# 官方来源年龄确认页

官方 HTML 适配器仅处理页面自己明确提供的 18+ 确认动作。当前 Circus 产品页的 `#confirm-yes` 按钮执行 `Cookies.set('PermitRate', '18', ...)` 后重载；适配器据此给原站点发送同域 `PermitRate=18` Cookie，并重新读取原始页面。

确认后页面继续走普通图片提取和筛选流程，候选记录带有 `age_gate_confirmed=true`。如果页面没有明确的 18+ 正向控件与 Cookie 动作，或确认后仍显示年龄门槛，来源继续进入人工复核。年龄拒绝按钮不会被触发，Cookie 不会发往其他域名。

图库里的 `/product/{brand}/{title}/` 是常见产品页路由。该路由前缀不会单独把页面下的 CG 判成商品图；图库路径、文件名、alt 和其他图像上下文继续参与图片类型判定。
