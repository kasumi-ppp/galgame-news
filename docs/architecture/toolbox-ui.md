# 工具箱中文界面

入口仍为项目根目录的 `00_启动工具箱.lnk`，通过 `启动工具箱.pyw` 加载 `src` 的当前代码。关闭旧窗口后重新启动即可使用本轮界面。

## 五页操作

- **新建任务**：拖放或选择 DOCX；文件名自动填入期号，可手动修改。选择输出目录与抓取选项。SocialData 默认关闭，任务只记录启用开关。
- **抓取进度**：显示新闻标题、阶段、完成数与异常事件数。暂停、继续、停止使用内部状态控制；中文摘要与可展开的原始诊断分开。停止仍遵循现有协作式取消。
- **图片审核**：三栏可拖动分隔条。新闻列表支持全部新闻，四个分类沿用审核决策。Ctrl/Shift 多选；A 入选、R 排除、P 待复核。预览支持缩放。来源链接、官网与原图入口不重新抓取图片。指定官网后可重试；审核地址绑定当前新闻与会话。
- **历史任务**：按期号搜索；选择记录后继续、查看图片或打开目录。移出历史仅更新目录记录，媒体文件保留。
- **设置**：跟随系统／浅色／深色保留原配置代码。密钥不回填；空字段保留旧值，成功保存后清空输入，只显示是否配置。

## 实现边界

`ui.py` 绘制本地线条图标和星光；无远程资源。`theme.py` 使用字体、调色板与共享样式，`i18n.py` 仅翻译显示文案。未知原因显示中文复核提示，原始值保留在技术详情。

缩略图和大预览经 `AsyncImages` 的两个后台线程解码为 QImage，界面线程创建 QPixmap。只派发可见范围附近的加载，队列最多 48，缩略图 LRU 最多 128；切换会话、新闻或分类后，旧 generation 的结果不显示。预览最大 2048×2048，小图不放大解码。

`AsyncExport` 在一个后台线程调用已有 `ReviewSession.export_final`，沿用原输出命名和文件校验；导出当前会话时暂停修改其决策及重试。输出结果显示实际导出数及未导出数。

本轮未修改爬虫、CG 筛选、付费查询及视频下载策略。单新闻重爬沿用现有同步控制器实现，大规模重爬仍可能暂时阻塞界面；本轮的异步处理覆盖图片显示及最终导出。

## 本地验收

独立目录：`output/toolbox_ui_20261002`。其中 `baseline` 是本轮开始前的桌面代码与已有补丁，`screenshots` 保存五页、浅深主题、100%／150%／200% 渲染及异常状态。`index.html` 为截图总览。

截图脚本 `scripts/capture_toolbox_ui.py` 使用本地历史图片的副本及 mock 索引；内存凭据库与独立任务目录，不构建真实爬虫或调用付费 API。`QT_QPA_PLATFORM=offscreen` 和 `QT_SCALE_FACTOR` 提供渲染证据，实体多屏切换与外部浏览器启动需在真实桌面另外观察。

## 精简图片交付（2026-10-07）

正式任务发布后自动生成 `final/images/xN`、`hN`、`zN`。已选图片位于新闻目录，待复核图片位于同目录的 `未候选` 子目录，采用 `x1.u01.png/jpg` 命名；人工排除及无有效审阅件的文件不作为备选导出。原件、索引、缓存和检查点仍供内部审核与续跑使用，不放进这份图片交付目录。

历史页和审核页的打开目录动作优先进入 `final/images`。审核仍提供待复核分页、人工接受/排除/待定以及快捷键。最终导出分别报告已选和备选数量。导出使用阶段目录与原子目录切换，旧清单管理的文件整体更新，人工加入的文件保留；反复导出不累积程序生成的编号副本，失败时保留旧交付。

## 抓取栏目选择（2026-10-07）

新建任务的“抓取栏目”提供新作、汉化、周报三个独立选项，默认全部勾选。周报包含现有 `zN` 的周边、业界及其他资讯。全部取消时提示“请至少选择一个抓取栏目”并禁用开始按钮。

共用任务参数 `selected_sections` 使用 `x/h/z`。新闻分析完成后、来源发现前过滤；未选新闻不采集页面、下载图片或查询 X API，也不生成交付目录。保留 DOCX 原始顺序、新闻 ID 及栏目编号，进度仅统计选中的新闻。所选栏目没有新闻时显示中文错误并结束，不启动采集。

历史续跑保留创建任务时的选择，修改范围需新建任务。旧任务参数缺失时全选；全选保留原检查点配置哈希，部分选择参与校验以阻止续跑改变范围。已选图片、`未候选` 备选目录和人工审核沿用现有流程，图片分类标准不变。离线回归覆盖七种非空组合、空选择、编号、请求隔离及续跑，不调用付费 API。

## 任务输出保留与旧精简任务（2026-10-08）

工具箱新建任务默认跳过视频。成功完成后，任务目录同时保留 `raw/`、图片索引、日志、检查点、媒体缓存、`review_state.json` 和 `final/` 图片交付；失败、取消或中断的任务也保留已有恢复数据。审核和历史续跑继续使用同一任务目录。

旧版已精简任务仍按“仅图片”历史记录处理：可以打开现有图片目录人工选择，但缺失的原件、索引、缓存、检查点和审核状态不会被虚构或从最终图片重建，也不能恢复为可审核或可续跑任务。进程在旧版精简目录切换中断时，启动恢复仅使用 `compact_output.py` 中按任务 ID 验证的唯一完整备份；该兼容恢复模块保留供此用途，不用于新任务清理。

运行开始时提前绑定实际任务目录，避免强制关闭后历史记录仍指向初始空目录。视频仍按默认设置采集；用户主动跳过视频时才关闭下载。

## 审核目录与 Windows 导出（2026-10-08）

导入任务总目录、`raw` 或同任务的 `final/images` 时，仅在明确的本任务布局内解析索引；索引缺失或不可读会提示，不能创建一个空审核会话。任务的 `raw` 索引对应同任务的 `final/images` 导出位置，AppData 中的历史目录和审核状态不作为图片来源。审核页分别显示来源和导出目录。

导出优先采用目录原子切换。Windows 拒绝重命名已有 `images` 目录时，改为在原目录内逐文件原子替换；变更前备份旧文件，只移除旧清单拥有的过期文件，保留用户新增文件。失败会回滚；回滚受文件锁阻碍时保留独立备份并提示其路径，不删除恢复数据。

接受、排除和待复核操作刷新缩略图后恢复当前滚动位置；当前图片离开分类时选中邻近项。延迟恢复校验会话、新闻、分页与刷新代数，切换新闻或分类不会被旧回调拉回原位置。
