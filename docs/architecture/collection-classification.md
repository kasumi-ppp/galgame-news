# 图片采集与局部分类

工具箱与 CLI 共用 `PipelineRunner`、官网解析器和筛选器。视频处理和 SocialData 查询策略保持原有实现。

## 资源、脚本与浏览器

官网获取资源后交给 `OfficialHtmlAdapter.parse()`。该纯解析入口同时处理静态 HTML 和浏览器快照。

脚本解析只接受与图库 DOM 明确关联的图片字面量数组，或带显式数量、索引与 URL 模板的有限 `Array.from`。不执行 JavaScript 表达式，不根据文件名试探图片编号。Summer Pockets 的五项列表关联 `galleryThumbnailTrack` 与 `galleryPreview`，原图记录相应缩略图关系，轮播克隆通过同新闻内的标准化 URL 去重。

无法解析的动态图库交给隔离 Chromium。默认条件启用，渲染并发 1，每页 20 秒、每条新闻最多 3 页、每页最多 40 次滚动/图库操作，资源请求上限 64。只操作明确的图库按钮或标签，忽略表单、购买、登录和任意页面链接。渲染同一 URL 不增加导航页面名额。暂停停止新操作，取消后关闭页面及上下文，已经取得的静态候选和诊断保留。

使用 [Playwright 的上下文请求拦截](https://playwright.dev/python/docs/network) 将文档、脚本、样式和 XHR 接入公共 `AsyncHttpClient`；禁用 service worker、WebSocket、分析请求及浏览器图片/视频/字体加载。浏览器提取 DOM 中的媒体地址，由正式图片下载器获取原件。公开 URL、逐跳重定向、大小、TLS、代理及取消限制沿用公共客户端。某些图库依赖图片 `onload` 才创建内容时，可能仍无法完整展开；此时明确保留诊断和待复核候选。

可选依赖为 `pip install -e ".[desktop,browser]"`，随后显式执行 `python -m playwright install chromium`。工具箱设置页提供中文开关、检查和安装按钮；默认不自动下载运行环境。源码启动的安装器使用当前环境的 `python.exe`，避免以 `pythonw.exe` 执行 pip。打包版不将自身 EXE 当作 Python 安装器；发行时应包含 Playwright，并提供匹配 Chromium 的安装说明。

## 商品导航

只在商品、通贩、复刻等新闻中导航。识别商品卡片（包括卡片本身为 `<a>`）、活动入口、详情按钮、官方商店入口及 JSON-LD Product。新闻明确提及的作品/商品先访问，同活动其他商品次之；过滤推荐区、购物车、登录、页脚和明显不同季节的旧活动。跨域仅进入新闻直接给出的链接或明确官方商店链接。与作品/图库导航共享三层和每新闻 16 页预算，保留根、父页面和导航文字。

`google-site-verification`、`baidu-site-verification` 等站点验证标签不是年龄确认。明确的 18 岁确认 Cookie 或同站 YES 入口继续处理。

## 证据和分类

`ImageCandidate.evidence` 默认空列表，旧索引兼容。每项包含页面、容器、图库/商品身份、局部文字、DOM/脚本/浏览器来源、变体关系。图片字段、`srcset`、弹窗和原图继承同一个局部项，不能由整页标题传播证据。

- `game_cg`：当前作品的事件/场景图库图片。
- `background_art`：标签或容器关系明确绑定的背景栏目图片；`bg` 文件名不能单独证明身份。
- `decorative`：栏目标题、分隔、导航控件、推荐区与页面皮肤，保留待复核且不自动入选。
- `goods`：有局部商品名称、价格、卡片/详情/结构化身份的商品图片；商品主图的 CSS 变体继承商品证据，不能一概当页面装饰。

图片自身的 Logo、立绘等角色优先于泛化图库文字，明确局部角色优先于普通文件名线索。`sample` 单词不能证明游戏截图。商品类型和新闻关联分开判断，厂牌活动可关联不同作品的商品，明确其他作品/活动/Steam ID 冲突仍拒绝。

背景在作品关联、类型和质量合格时可自动入选。排序保持 X 照片最高，事件 CG 在背景之前；仍受新闻内去重、原图质量、类型数量限制和每新闻最多 20 个不同画面的共同上限约束。重复与超额候选留在待复核目录。

原件和 PNG/JPG 审阅图沿用原链路。审核加载器保留结构化证据和媒体下载状态，最终导出采用已验证的审阅图。离线适配器明确提供的本地图片先验证并复制到本任务，再登记检查点；恢复时继续拒绝任务外资产路径，不按文件名找替代文件。

## 验收口径

冻结 263 页面、脚本、已有原图及 57 张缓存 X 照片重放，不联网爬取、不读 API 凭据。当前输入链接和预算内导航与旧搜索来源范围不同，候选总数变化不能当整体发现率。缺少的冻结详情页和原件单独列出。已标注样本报告 CG、背景和装饰表现；未标注预测不进入精确率分母，不能据此宣称整体精确率达到门槛。
