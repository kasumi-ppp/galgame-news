Galgame 新闻工具箱 Windows 私测版
===============================

感谢参与测试。本包仅供获授权的少数测试者使用，请勿公开分享安装包或其中的私测配置。

一、启动
------

1. 将 ZIP 完整解压到一个有写入权限的普通文件夹；不要只从压缩包预览窗口运行。
2. 在解压目录根目录双击“00_启动工具箱.cmd”启动。也可以进入 GalgameNewsToolbox 文件夹，双击 GalgameNewsToolbox.exe。
3. 首次启动需要几秒钟初始化。Windows SmartScreen 若提示未知发布者，请按测试包发布者提供的私测指引处理；不要从其他来源下载替代文件。

请保留解压后的整个目录结构，不要单独移动 EXE 或删除 _internal 等运行文件。设置和任务历史保存在 Windows 本机应用数据目录中。首次使用时，默认 output 目录位于解压后的工具箱目录中；如果此前已保存过默认输出目录，则沿用“设置”中的位置。任务本身的输出目录可在“新建任务”中选择。

二、准备输入与开始任务
--------------------

1. 在“新建任务”页选择或拖入本期周报 DOCX。期号会尝试从文件名自动填写，也可以手动修改。
2. 选择输出目录。建议每次测试使用独立目录，方便定位结果。
3. 选择要抓取的栏目：新作（x）、汉化（h）、周报（z）；至少选择一个。默认全选。
4. 默认勾选“跳过视频，仅抓取图片”。若要测试视频，取消勾选；视频抓取使用包内附带的 FFmpeg/ffprobe 9.0.1。
5. “离线模式”只使用本地及已索引来源，适合无网络的界面/恢复流程检查；在线采集需联网。
6. 点击“开始抓取”，可在“抓取进度”页查看当前状态。

三、API 与 X 媒体
----------------

本测试包带有经授权的私测 SocialData 配置。首次启动时应用会将其导入当前 Windows 用户的凭据库；如果该账户已配置自己的 SocialData key，不会覆盖已有值。导入成功后，包内一次性授权文件会自动删除。ZIP 本身仍包含该私测配置，因此只可在获授权的小范围内分发，切勿公开分享。应用设置页只显示“已配置/未配置”，不会回填密钥。

SocialData 默认关闭。要通过 SocialData 查询 X 帖子媒体，请在新建任务页明确勾选“本次任务使用 SocialData 获取 X 媒体”。勾选后按帖子查询会使用私测账户余额；请仅在获授权的测试任务中启用，避免重复或大批量查询。未勾选时不会启用这项 SocialData 查询。

不要把本测试包、凭据库内容、密钥、设置文件或包含密钥的截图/日志转发给未获授权的人。不要在反馈中粘贴任何 API key、Bearer token 或 Authorization 请求头。其它 API 凭据（例如 X Bearer Token、TwitterAPI.io、Brave）如确需测试，由测试者在“设置 → API 配置”中自行填写；密钥存入 Windows 凭据库，不写入普通设置 JSON。留空即可跳过相应凭据功能。SocialData 是可选项且每次任务默认关闭。

四、检查结果、暂停与恢复
----------------------

- 图片采集完成后打开“图片审核”，按新闻逐条查看、接受或排除图片；也可以从“历史任务”重新打开可审核任务。
- 支持“暂停”和“继续”当前运行任务。需要停止时使用进度页的停止操作；遇到失败或中断时不要删除任务输出目录，可从“历史任务”尝试恢复。
- 某条新闻可在审核页单独重试。重试结果会作为新尝试合并到审核视图，不应覆盖原始采集数据。
- 任务成功、失败、停止或中断后，已生成的任务输出都会保留。完整任务目录包含 raw、图片索引、checkpoint、缓存、review_state 和 final 图片交付；不要手工删除这些任务内部文件。
- 旧版已精简为仅图片的历史任务可以打开现有图片目录人工选择，但缺失的原件、索引、缓存、检查点和审核状态不会从 final/images 重建，也不能恢复审核或续跑。
- 视频任务的结果请检查任务输出中的视频文件；如果 FFmpeg/ffprobe 未就绪，先在“设置 → 视频工具”点击“检查视频工具”，并把状态提供给发布者。

五、浏览器运行时与可选视频组件
----------------------------

动态网页浏览器增强依赖与应用匹配的 Playwright 和 Chromium 1243（含 headless 组件），已随包提供。设置页可以检查浏览器状态；“安装浏览器组件”会联网安装组件，通常不需要执行。浏览器组件已通过本机离线自检。动态浏览器只访问公开网页，不读取 API 凭据或现有浏览器配置。

FFmpeg/ffprobe 9.0.1 已随包提供，并通过本机离线自检。设置页的“检查视频工具”会报告是否找到以及使用的路径。该测试包尚未在干净的其他 Windows 机器上验证；也未使用付费 API 做实际收费验证。若组件诊断失败，请将状态反馈给提供本测试包的人。
